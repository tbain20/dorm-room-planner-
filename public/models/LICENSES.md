# Model licenses

Running per-file ledger, extending `LICENSE.txt`'s blanket statement with source/license/author
detail for each individual model. Every file below was verified CC0 (public domain, no
attribution required) before being added — nothing with an unclear, ambiguous, or account-gated
license made it into this folder. If you ever need to re-verify one, re-download from the same
source URL and compare file size/checksum.

**Sources checked but not used**: Quaternius, Poly Pizza, Sketchfab (filtered to
Downloadable + CC0), and itch.io furniture-asset packs were all considered for the August 2026
"furniture sourcing" pass (see README → "Furniture sourcing"). Kenney's Furniture Kit alone turned
out to have enough unused, clearly-CC0 pieces to cover every category in that brief, so nothing
was pulled from the other four — not because they're unusable, just unnecessary this round. Worth
revisiting them directly if a future category needs options this kit doesn't have.
